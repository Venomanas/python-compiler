# python-compiler
a simple python compiler website with dynamic inputs and display outputs 


🐍 Simple Python Compiler
A clean, web-based interface to write and run Python code directly in your browser. This project provides a simple code editor for dynamic inputs and an output console to display the results instantly.

![Uploading image.png…]()



✨ Features
Live Code Editor: Write your Python code in a simple, numbered editor.

Instant Execution: Click the "Run" button to process your code.

Real-time Output: See the results, print statements, or errors from your script displayed in the output console.
